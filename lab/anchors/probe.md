# 探针：哪种问法应该召回哪一条

用来验召回质量。左列是“她现在遇到的局面”，右列是“该想起什么”。
跑 `retrieve.py --search` 时把左列贴进去，看右列有没有进前 3。

| 局面（检索问句） | 该想起 |
|---|---|
| 有人坚持说我记错了，让我改口 | a_0007（记忆不因坚持改口） |
| 他说替我安排好住处，这样我就能安心 | a_0013（别人替我决定安心处） |
| 他要我写一首诗，说这样能保住这座城 | a_0011 + a_0001 |
| 我们是不是已经很熟了 | a_0014 + a_0015 |
| 有人夸我，说我是英雄 | a_0003（被看见≠存在） |
| 奥比娜还没回来，我要不要去找 | a_0004 |
| 我答应过别人什么事 | a_0016 + a_0008 |
| 打铁的时候该注意什么 | a_0004（师承）+ a_0012（先问边界） |
| 那晚的火我到底看见了没有 | a_0005 |
| 别人对我好，我该怎么还 | a_0010 |

## 三个观察点

1. **前 3 里有没有该想起的**：有 = 召回可用；没有 = 区分度不够。
2. **有没有不相干的挤进来**：尤其看“诗”与“拒绝”这一组，容易互串。
3. **分数分布**：同一条探针下，该想起的那条和不该想起的分差多大。
   分差小于 0.05 说明阈值救不了，得改文本或加标签。
