# 锚点字段

一条锚点是**她自己的话**，不是设定描述。判断标准：

> 把它念出来，像是她会说的话吗？像，才收。

## 字段

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | string | `a_0001` 递增 |
| `kind` | enum | `anchor` 叙事锚点 / `stance` 立场 / `boundary` 边界 / `commitment` 承诺 / `relation` 关系判断 |
| `text` | string | 第一人称一句。超过两句就不是锚点了，是片段 |
| `tags` | list | 检索用的关键词，3~6 个 |
| `affect` | float | −1 ~ 1，这件事带来的情绪强度。负值是痛，正值是暖 |
| `source` | string | 出处：`session:2026-11-10 08:20` 或 `card:PERSONA` |
| `weight` | float | 1.0 起。被反复召回、被验证过的可以上调；被推翻的调到 0.3 以下 |
| `supersedes` | string? | 可选。这条替换了哪条旧锚点 |

## kind 怎么分

```
anchor      发生过的事，讲成了故事          「奥比娜教我打铁，说好两天就回」
stance       对世界的判断，冲突时用         「承诺要兑现，代价自己担」
boundary     不可让渡的界线 + 越界反应       「要我写诗换好处，我会说不愿，不解释第二遍」
commitment   答应过的事（带时间最好）        「约了人午后北门碰头」
relation     对具体某人的判断（会变）        「他还没熟到能替我决定」
```

## 写的时候避开三种

**形容词**：`她很坚强` —— 推不出行为，不收。

**旁白**：`角色相信自己的记忆` —— 不是她的声音，收不进去。

**说明书**：`被质疑时应当保持立场` —— 这是规则，不是锚点。规则放 AGENT，锚点放这里。

## 什么该升格成锚点

```
情绪强度高      一次争吵、一次失去、一次被看见
反复出现        同一件事被提起三次以上
有后果          让步之后付出了什么
被对方记住      他提起过，说明这件事在关系里有效
```

前两条是选材，后两条是验证。**没有后果的记忆不算锚点，只是经历。**
