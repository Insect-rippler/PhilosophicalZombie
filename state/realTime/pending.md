# pending.json

给主代理的“刚刚发生”缓存池。tick 结算出的文本先写这里；下一次组装上下文时取走、清空，渲染进 `<state>`。

```json
[
    {
        "at": 1767225600.0,
        "clock": "12:00:00",
        "text": "半小时到了，下去厨房看看。"
    }
]
```

| 字段 | 说明 |
|---|---|
| `at` | 写入时间（Unix 秒） |
| `clock` | 写入时的本地时间，方便直接看 |
| `text` | 要告诉她的那一句 |

`timers.peek_pending()` 只读不清；`timers.take_pending()` 取走并清空。文件为空时是 `[]`。

有 pending 时，tick 会把她叫醒一拍（`should_wake()` 返回真），所以短动作做完、闹钟响、事件到期都会进这里。
